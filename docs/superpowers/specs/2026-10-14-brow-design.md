# Brow — дизайн MVP

Дата: 2026-10-14

## Цель

Использовать пустую область вокруг выреза («чёлки») MacBook Pro 14" (M1) как мини-панель в стиле Dynamic Island. Приложение для личного использования, без App Store и нотаризации.

## Поведение

- Agent app: нет иконки в Dock (`LSUIElement = YES`). Выход — через контекстное меню (правый клик) по панели.
- Прозрачное окно висит поверх выреза. В свёрнутом виде — чёрная «капля» размером с вырез, сливается с ним.
- Курсор попадает в зону выреза (вырез + ~10 pt по краям) → панель плавно (SwiftUI spring) расширяется вниз до ~480×200 pt со скруглением снизу.
- Курсор покидает рамку панели → через 0,3 с панель сворачивается. Возврат курсора раньше отменяет сворачивание.
- Пока фокус ввода в заметке, панель не сворачивается.
- Перетаскивание файла к вырезу раскрывает панель сразу на вкладке «Полка».
- Перетаскивание текста к вырезу раскрывает панель на вкладке «Буфер»; отпущенный текст записывается в историю буфера (системный буфер обмена не меняется).

## Компоновка развёрнутой панели

- Сверху всегда — блок музыки.
- Под ним — переключатель-иконки вкладок: «Полка / Буфер / Заметки».

## Функции MVP

### Музыка (любой плеер, включая браузер)
- Обложка, название, исполнитель, приложение-источник.
- Play/pause, предыдущий/следующий трек, перемотка ползунком.
- Источник — приватный фреймворк MediaRemote через helper, запускаемый в `/usr/bin/perl` (единый путь для macOS 15.3 и 15.4+; на 15.4+ Apple закрыла MediaRemote для сторонних приложений, но системный perl имеет нужные права).

### Полка для файлов
- Перетащил файл/папку на вырез → на полке хранится ссылка (security bookmark) на оригинал; файл не копируется.
- Перетаскивание с полки отдаёт URL файла; копировать или перемещать — решает получатель (Finder).
- Кнопка «×» убирает элемент с полки (файл не трогается), «Очистить всё».
- Если оригинал удалён (bookmark не разрешается) — элемент исчезает. Устаревший bookmark (`isStale`) пересоздаётся.
- Полка сохраняется между перезапусками. Перетаскивание текста на полку не попадает — оно идёт в историю буфера.

### История буфера обмена
- Только текст, последние 50 записей, сохраняется между перезапусками.
- Повтор существующей записи поднимает её наверх (без дубликатов).
- Поиск по подстроке без учёта регистра.
- Клик по записи кладёт её в буфер; это изменение помечается как собственное и не добавляет дубликат.
- Пропускаются: данные с маркерами `org.nspasteboard.ConcealedType` / `org.nspasteboard.TransientType` (менеджеры паролей), пустые и пробельные строки.
- Строки длиннее 10 000 символов показываются обрезанными, копируются целиком.

### Быстрые заметки
- Один блокнот — одно текстовое поле, автосохранение с задержкой ~0,5 с.

## Архитектура

Swift Package (Swift 6.1, macOS 14+) с тремя таргетами; `.app` собирается скриптом (`make app`).

### `BrowCore` — библиотека, чистая логика, покрыта тестами
- `NotchGeometry` — по параметрам экрана (`frame`, `safeAreaInsets.top`, `auxiliaryTopLeftArea`, `auxiliaryTopRightArea`) вычисляет прямоугольник выреза, зону наведения и рамку развёрнутой панели. Без выреза → `nil`.
- `PanelStateMachine` — состояния `collapsed → expanded → collapsing`, задержка 0,3 с, правила фокуса заметки и drag файла (выбор вкладки). Время через инжектируемые часы.
- `ClipboardHistory` — лимит, дедупликация, поиск, фильтрация.
- `ShelfStore` — элементы как bookmarks, восстановление, отбрасывание неразрешимых.
- `NotesStore` — текст + debounce-сохранение.
- `NowPlaying` — модель трека и парсер JSON-строк helper'а.
- `Storage` — JSON-файлы в `~/Library/Application Support/Brow/`, атомарная запись.

### `Brow` — исполняемый таргет, AppKit + SwiftUI
- `AppDelegate` — запуск, защита от второго экземпляра (`NSRunningApplication` с тем же bundle id).
- `NotchPanel` / `NotchWindowController` — `NSPanel` без рамки, уровень выше строки меню, `canJoinAllSpaces` + `fullScreenAuxiliary`; окно всегда размера развёрнутой панели, в свёрнутом состоянии `ignoresMouseEvents = true`; в развёрнутом может стать key window.
- `MouseTracker` — глобальный + локальный мониторы `mouseMoved` / `leftMouseDragged` (без прав Accessibility); drag файла определяется по `NSPasteboard(name: .drag)` с `fileURL`.
- `ClipboardWatcher` — опрос `NSPasteboard.general.changeCount` каждые 0,5 с.
- `MediaController` — держит процесс `perl brow-media.pl stream`, читает строки JSON, досчитывает позицию между событиями; команды через `perl brow-media.pl send <command> [arg]`.
- SwiftUI: `NotchRootView`, `MusicView`, `ShelfView`, `ClipboardView`, `NotesView`.

### `BrowMediaRemote` — динамическая библиотека C/ObjC + `brow-media.pl`
- Библиотека загружает MediaRemote (`dlopen`), подписывается на уведомления now playing и выводит JSON-строку на каждое изменение: `title`, `artist`, `album`, `artworkBase64`, `duration`, `elapsed`, `timestamp`, `playbackRate`/`isPlaying`, `bundleId`.
- Команды: `play`, `pause`, `toggle`, `next`, `previous`, `seek <seconds>`.
- `brow-media.pl` загружает библиотеку через `DynaLoader` и вызывает нужную точку входа.

## Геометрия окна и экраны

- Используется экран с `safeAreaInsets.top > 0` (встроенный дисплей). Ширина выреза — промежуток между `auxiliaryTopLeftArea` и `auxiliaryTopRightArea`; высота — `safeAreaInsets.top`. Никаких захардкоженных размеров.
- Пересчёт при `NSApplication.didChangeScreenParametersNotification`.
- Нет экрана с вырезом (например, закрыта крышка) → панель скрыта, приложение ждёт смены экранов.

## Обработка ошибок

- Helper упал/закрыл stdout → перезапуск с backoff 1 → 2 → 4 … ≤ 30 с; блок музыки показывает «Нет данных о воспроизведении», кнопки неактивны.
- Ничего не играет → «Ничего не играет».
- Битая JSON-строка пропускается, пишется в `os.Logger` (категория `media`).
- Повреждённый файл хранилища → переименовывается в `*.corrupt`, данные начинаются с пустого состояния, событие логируется.

## Тестирование

Автотесты (`swift test`, XCTest; `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`) для `BrowCore`:
- `NotchGeometry`: MBP 14" (1512×982, вырез ~185×32 pt); экран без выреза; смещённые координаты (внешний монитор слева/сверху).
- `PanelStateMachine`: наведение, уход, возврат до таймаута, фокус в заметке, drag файла → вкладка «Полка».
- `ClipboardHistory`: лимит 50, дедупликация, поиск, пропуск concealed/пустых.
- `ShelfStore`: добавление/удаление, отбрасывание неразрешимых bookmarks (временные файлы).
- `NowPlaying`: полная, частичная, битая строка, пустое событие.
- `Storage`: round-trip, повреждённый файл.

Ручная проверка на MacBook: нет иконки в Dock; капля на месте выреза; раскрытие/сворачивание; строка меню под окном кликабельна; музыка из Apple Music и YouTube в браузере; drag файла на полку и обратно на рабочий стол; буфер — копирование, поиск, возврат; заметка переживает перезапуск.

## Вне MVP

Автозапуск при входе, настройки, несколько мониторов, картинки в буфере, горячие клавиши, подпись и нотаризация.
