# Brow MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agent-приложение для macOS, которое превращает вырез MacBook Pro 14" в раскрывающуюся панель (музыка, полка файлов, история буфера, заметка).

**Architecture:** Swift Package из трёх таргетов: `BrowCore` (чистая логика + XCTest), `Brow` (AppKit-окно `NSPanel` + SwiftUI-вью), `BrowMediaRemote` (ObjC-dylib, загружаемая в `/usr/bin/perl`, отдаёт now playing строками JSON). `.app` собирает `Makefile`.

**Tech Stack:** Swift 6.1 (swift-tools-version 6.0, language mode 5 для таргета `Brow`), SwiftUI + AppKit, macOS 14+, XCTest, Objective-C (ARC), perl 5.34 (`/usr/bin/perl`, DynaLoader).

**Spec:** `docs/superpowers/specs/2026-10-14-brow-design.md`

## Global Constraints

- Все команды сборки/тестов — через `make` (Makefile экспортирует `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`; системный `xcode-select` не трогаем).
- Минимальная ОС: macOS 14.0. Bundle id: `com.freedrobili.Brow`. `LSUIElement = YES`.
- Хранилище: `~/Library/Application Support/Brow/` — `clipboard.json`, `shelf.json`, `notes.json`.
- Развёрнутая панель: 480×200 pt; зона наведения: вырез + 10 pt слева/справа/снизу; задержка сворачивания 0,3 с; анимация `spring(response: 0.35, dampingFraction: 0.8)`.
- Буфер: только текст, лимит 50, превью 10 000 символов, опрос каждые 0,5 с, пропуск `org.nspasteboard.ConcealedType` / `org.nspasteboard.TransientType`.
- Заметка: автосохранение через 0,5 с после последнего изменения.
- Helper музыки: backoff перезапуска 1 → 2 → 4 … ≤ 30 с.
- Логи — `os.Logger(subsystem: "com.freedrobili.Brow", category: ...)`; категории `storage`, `media`, `shelf`.
- Тексты UI — на русском, точные строки: «Ничего не играет», «Нет данных о воспроизведении», «Перетащите файлы сюда», «Очистить всё», «Поиск», «Выйти из Brow».
- Внешних зависимостей (SPM-пакетов) нет.

## Review Focus

1. **Файл перемещён в Корзину** — bookmark продолжает разрешаться (в `~/.Trash`), но пользователь считает файл удалённым → элемент должен исчезнуть с полки. Тест в Task 5 (`isInTrash`).
2. **Один и тот же файл брошен на полку дважды** → один элемент. Тест в Task 5.
3. **Выход из приложения в течение 0,5 с после набора текста** → текст не теряется (`flush()` в `applicationWillTerminate`). Тест `flush` в Task 6, вызов — в Task 13.
4. **Brow упал или закрыт — helper-процесс perl остаётся сиротой** → helper завершается по EOF на stdin. Проверка в Task 8.
5. **Курсор над пунктами строки меню рядом с вырезом** (внутри рамки окна, но вне зоны наведения) → панель НЕ раскрывается, клики проходят. Тест в Task 3, проверка кликов — в Task 9.

### Task 3: PanelStateMachine

**Files:**

**Interfaces:**

- Produces:
  ```swift
  public enum PanelTab: String, Codable, Sendable, CaseIterable { case shelf, clipboard, notes }
  public enum PanelState: Equatable, Sendable { case collapsed, expanded, collapsing(deadline: Date) }
  public struct PanelStateMachine: Sendable {
      public static let collapseDelay: TimeInterval = 0.3
      public var geometry: NotchGeometry              // set → state = .collapsed
      public private(set) var state: PanelState       // начально .collapsed
      public private(set) var selectedTab: PanelTab   // начально .shelf
      public var isEditingNote: Bool                  // начально false
      public var isExpanded: Bool { get }             // state != .collapsed
      public init(geometry: NotchGeometry)
      public mutating func mouseMoved(to point: CGPoint, now: Date)
      public mutating func fileDragMoved(to point: CGPoint, now: Date)
      public mutating func tick(now: Date)
      public mutating func select(_ tab: PanelTab)
  }
  ```
  Правила `mouseMoved`: collapsed + `hoverRect.contains` → expanded; expanded + `!panelRect.contains` + `!isEditingNote` → `collapsing(now + 0.3)`; collapsing + `panelRect.contains` → expanded. `fileDragMoved`: как `mouseMoved`, плюс при попадании в `hoverRect` (или в `panelRect`, если уже раскрыта) → `selectedTab = .shelf`. `tick`: collapsing и `now >= deadline` и `!isEditingNote` → collapsed.
