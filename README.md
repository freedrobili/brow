# Brow

Brow превращает вырез («чёлку») MacBook Pro в мини-панель в стиле Dynamic Island. Наведите курсор на вырез, и из него плавно выезжает панель с виджетами. Уведите курсор, и панель свернётся.

Brow работает как agent-приложение: иконки в Dock нет. Чтобы выйти, кликните правой кнопкой по раскрытой панели и выберите «Выйти из Brow».

## Что умеет

- **Музыка:** название, обложка и прогресс того, что сейчас играет, в любом плеере, включая видео в браузере. Есть play/pause, предыдущий/следующий трек и перемотка ползунком.
- **Полка:** перетащите файл или папку к вырезу, и они лягут на полку. Потом вытащите их оттуда в любое место. На полке хранится ссылка на файл, сам файл не копируется. Если оригинал удалить или отправить в Корзину, он исчезнет с полки.
- **Буфер:** последние 50 скопированных текстов с поиском. Клик по записи снова кладёт её в буфер обмена. Тексты из менеджеров паролей не сохраняются. Перетащите выделенный текст к вырезу, и он тоже попадёт в историю.
- **Заметка:** один блокнот с автосохранением. Пока вы печатаете, панель не сворачивается.

Данные лежат в `~/Library/Application Support/Brow/`.

## Сборка и запуск

Нужны macOS 14+ и установленный Xcode в `/Applications/Xcode.app`. `xcode-select` переключать не нужно: Makefile сам подставляет `DEVELOPER_DIR`.

```bash
make install  # установить в ~/Applications, закрепить в Dock и запустить
make run    # собрать build/Brow.app и запустить
make app    # только собрать
make test   # автотесты BrowCore
```

После `make install` Brow запускается кликом по иконке в Dock или через Spotlight (⌘Пробел → «Brow»). Повторный `make install` обновляет установленную версию, второй ярлык в Dock не появится. Иконку рисует `scripts/make-icon.swift`.

## Как устроено

- `Sources/BrowCore` — вся логика без UI, покрыта тестами: геометрия выреза, состояния панели, история буфера, полка, заметка, разбор данных о музыке.
- `Sources/Brow` — приложение: окно `NSPanel` над вырезом, отслеживание мыши, SwiftUI-виджеты.
- `Sources/BrowMediaRemote` + `Resources/brow-media.pl` — helper для музыки. Данные о воспроизведении берутся из приватного фреймворка MediaRemote. Начиная с macOS 15.4 Apple пускает к нему только свои процессы, поэтому helper загружается в системный `/usr/bin/perl`.

## Ограничения

- MediaRemote — приватный API Apple, и будущие версии macOS могут его сломать. Тогда блок музыки покажет «Нет данных о воспроизведении», а остальное продолжит работать.
- Поддерживается только встроенный экран с вырезом. Если крышка закрыта и работает только внешний монитор, панель скрыта.
- Сборка подписана ad-hoc, только для личного использования.
